11–12월 원고의 질문 유형을
웹에서도 보여 주자는 제안

인쇄본은 원고 표기를 읽어 OX 동그라미, 체크칸, 선 잇기 점을 자동으로 그립니다. 웹은 지금 질문을 글자로만 저장해서 모든 질문이 입력칸으로 보입니다. 원고는 그대로 두고, 질문 유형 정보만 새 칸에 함께 실어 보내면 웹도 같은 활동 화면을 보여 줄 수 있습니다. 아래 샘플 화면은 실제 11–12월 원고를 변환한 데이터로 동작합니다.

원고는 그대로9가지 유형은 원고 표기(①, □, (O / X), A↔① …)에서 자동 판별합니다.

샘플 화면

날짜와 연령을 바꿔 보세요. 보기를 누르고, 선을 잇고, 따라 써 볼 수 있습니다. ‘교사 보기’를 켜면 답변 가이드와 정답 확인이 나옵니다.

이 날의 문항 판별 결과

화면에서 달라지는 것

  • 머리: 날짜 배지·요일(‘주일’), 성경 주소 리본, 이번 주 주제. 청소년·청년은 큰 날짜 숫자와 굵은 제목.
  • 성경: 절 번호를 작게, 어휘 낱말에 형광펜.
  • 해설: 3문단을 문단 그대로(9–10월은 한 문단으로 붙어 보였음).
  • 질문: 유형별 활동 화면 + 문항 아래 작은 안내.
  • 답변 가이드: 독자에게는 숨기고 교사·관리자만.

샘플은 정적 페이지라 저장은 하지 않습니다. 실제 화면에서는 지금처럼 personal_notes에 문항별로 저장합니다(아래 ‘데이터 구조’ 참고).

단계 제안

  1. 11/1 오픈: 화면 정리(머리·주제·해설 문단·연령 색·답변 가이드 숨김). 질문은 지금 입력칸. 저학년은 기존 활동 화면용 원고(2활동)를 그대로 사용.
  2. 12월 이후: question_meta를 채워 유형별 화면을 단계적으로 켬(NULL이면 자동으로 예전 화면).

합의할 것

  1. 새 칸 question_meta(권장) vs 기존 questions 원소를 객체로 바꾸기(학생 화면·편집 화면·노트 인덱스·베트남어 생성기를 동시에 고쳐야 함).
  2. 9–10월 한국어 SQL 생성기 원본 위치. 이번 생성기와 합쳐 저장소에 둘지.
  3. 정답 표시: 바로 채점(정답 공개) / 저장만 / 교사만 확인.
  4. 저학년 웹: 지금처럼 2활동(말씀 활동·실천 활동)만, 아니면 인쇄처럼 3문항 모두.
  5. 연령 색을 인쇄와 맞출지(저 코랄 · 고 하늘 · 청소년 청록 · 청년 남색).
